# AI Customer Support Copilot

Generative AI copilot for assisting customer support agents
in a fictional German e-commerce company.

## Status

Product Discovery

## Business Goal

Reduce customer request handling time and improve response
consistency while keeping human support agents in control.

## Initial MVP Scope

- Shipping
- Returns
- Refund Policy
- Order Status

Supported languages:
- German
- English
